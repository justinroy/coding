All About Coding

What can coding do?

  • Coding can write, edit, and put text
  • Can repeat tasks over and over automatically
  • Makes electronic cars, robots & drones tick
  • Every software program is made by code
  • Using digital tools = interacting with data = using code
  • Software tools work with data that includes code
  • Building apps definitely involves code

The coding process

  • Takes several steps
  • Can be hard for humans to read directly
  • Helps identify and solve problems
  • 100+ major programming languages (and 700+ overall!)
  • Compilers & interpreters turn human-friendly code into machine code
  • Keep tweaking & testing until it works

Coding careers

  • Many students major in code-related subjects in college
  • Some create websites, others build software
  • Computer Science is the most common degree
  • Programming is one of the fastest-growing U.S. careers
  • Some write code that helps people use computers more easily
  • U.S. coders can earn $49 k – $94 k per year (role-dependent)
  • There’s big money in many coding jobs
