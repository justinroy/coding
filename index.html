All About Coding

What can coding do?

  • Write, edit, and style text
  • Repeat tasks automatically (no chores!)
  • Run electronic cars, robots & drones
  • Every software program is powered by code
  • Using digital tools = working with code
  • Apps? 100 % code behind the scenes

The coding process

  • Break big ideas into little steps
  • Find and fix problems (called bugs)
  • 100+ popular languages (700 overall!)
  • Compilers translate human code → machine code
  • Test, tweak, repeat … until it works!

Coding careers

  • Lots of students major in Computer Science
  • Create websites, build software—endless choices
  • Programming = one of the fastest-growing careers
  • Coders can earn $49 k – $94 k per year (or more!)

Coding jobs

  • Mobile App Developer
  • Machine-Learning Engineer
  • …and tons more!
